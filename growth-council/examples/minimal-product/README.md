# Exemplo mínimo

Este diretório contém só um produto e contexto. A execução completa é:

```bash
python3 ../../run_council.py analyze --root .
```

O comando cria o contexto normalizado, diagnósticos independentes, pacotes de execução e outputs `DRAFT`. Isso é intencional: sem pesquisa ou métricas, o Council deve expor hipóteses em vez de produzir um veredito fictício.
